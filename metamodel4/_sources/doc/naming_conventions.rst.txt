Discussion about naming conventions
===================================  

Naming convention are very important. Currently we have 2 proposals for the ``wrapper`` and the ``wrapper description file``.

 1) Naming used in the current documentation

    - Component Specification file 

    - Component Adapter
  
    - ``*.acs*``  file extension


 2) Older version

    - Function Specification file 

    - Function Adapter
  
    - ``*.afs*``  file extension


Feedback and proposals welcome.
